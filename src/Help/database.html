Database Schema

SQL Server database divided into 7 schemas. Full schema scripts live in DatabaseSchema/FullSchema.sql. Incremental alter scripts follow the naming convention Alter_YYYYMMDD_Description.sql.

Naming conventions
  • Primary keys: TableNameId (INT IDENTITY or TINYINT for small lookup tables)
  • Timestamps: all UTC, stored as DATETIME2(3)
  • Soft delete: DeletedAt DATETIME2(3) NULL — non-null = deleted
  • Audit columns: CreatedAt, UpdatedAt — set via SYSUTCDATETIME()
  • Slugs: lower-kebab-case, URL-safe, generated from display names

itil.Problem

Columns: ProblemId, Number, Title, RootCause, Workaround, PriorityId (FK → lookup.Priority), StateId (FK → lookup.ProblemState), IsKnownError, AssigneeUserId, GroupId, OpenedAt, ResolvedAt, DeletedAt, UpdatedAt.

itil.Change

Columns: ChangeId, Number, Title, Description, RolloutPlan, RollbackPlan, ImpactNotes, ChangeTypeId (FK → lookup.ChangeType), RiskId (FK → lookup.Risk), StateId (FK → lookup.ChangeState), OwnerUserId, GroupId, CabId, ScheduledStart, ScheduledEnd, DowntimeEstimate, SubmittedAt, ApprovedAt, CompletedAt, DeletedAt, UpdatedAt.

itil.ChangeReviewer

Join table between Change and User with vote data. Columns: ReviewerId, ChangeId (FK → itil.Change), UserId (FK → core.User), VoteId (FK → lookup.ApprovalVote), Comment, VotedAt.

Stored Procedures in itil schema

  • itil.usp_AddComment — inserts a audit.Comment row, writes an ActivityEvent, and creates Notification rows for all watchers of the parent ticket in a single transaction.

reporting schema — Stored Procedures

ProcedureCalled byDescription
reporting.usp_DashboardKpis SlaRepository.GetStatsAsync Returns a single row: open incidents, SLA at-risk count, changes this week, avg resolution minutes, SLA met %, breach count. Parameter: @Days INT.
reporting.usp_EvaluateSlaBreaches SlaBackgroundService (every 60s) Creates #breached and #warned temp tables, calculates elapsed time vs SLA target for all open non-deleted incidents, updates SlaBreachedAt, SlaWarnedAt, and SlaPercent in itil.Incident.
