Interfaces

All interfaces live in ApertureITSM.Core/Interfaces/. They define the contracts between layers — the API and Feature layers depend on these interfaces, never on concrete classes. Implementations live in Infrastructure (repositories) or Feature projects (services).

Design rule
The Core project has zero dependencies on Infrastructure or Features. Any code that imports from Core is safe to test in isolation via mock implementations of these interfaces.

Repository Interfaces

Implemented by the classes in ApertureITSM.Infrastructure. Each interface covers one domain area.

IIncidentRepository · Interfaces/IIncidentRepository.cs

Implemented by IncidentRepository. Registered as Scoped in DI.

  • GetPagedAsync(IncidentFilter, page, pageSize) → Returns a paged, filtered list of incidents. IncidentFilter supports search text, status, priority, assignee, SLA-at-risk flag, unassigned flag, and include-resolved flag.
  • GetByIdAsync(incidentId) → Returns a single incident with all joined data, or null if not found.
  • CreateAsync(CreateIncidentRequest) → int Inserts a new incident row and returns the generated IncidentId. CreateIncidentRequest carries title, description, priorityCode, serviceId, categoryId, ciId, reporterExtId.
  • UpdateStatusAsync(id, statusCode, actorUserId) → void Transitions the incident status; writes an ActivityEvent record.
  • UpdateAssigneeAsync(id, assigneeExtId, actorUserId) → void Assigns the incident to a user by external ID; writes an ActivityEvent.
  • UpdatePriorityAsync(id, priorityCode, actorUserId) → void Changes priority; writes an ActivityEvent.
  • UpdateFieldAsync(id, field, value, actorUserId) → void Generic field update (title, description, etc.); writes an ActivityEvent.
  • LinkToProblemAsync(incidentId, problemId) → void Sets the ParentProblemId FK on the incident.
  • SoftDeleteAsync(incidentId, actorUserId) → void Sets DeletedAt (soft delete / close); writes an ActivityEvent.

IProblemRepository · Interfaces/IProblemRepository.cs

Implemented by ProblemRepository.

  • GetAllAsync(includeResolved)→Returns all problems, optionally filtering out resolved/closed ones.
  • GetByIdAsync(problemId)→Returns a single problem with affected services enriched.
  • CreateAsync(CreateProblemRequest)→ intInserts a new problem; returns the new ProblemId.
  • UpdateStateAsync(id, stateCode, actorUserId)→ voidState transition with ActivityEvent write.
  • UpdateFieldAsync(id, field, value, actorUserId)→ voidGeneric field update (rootCause, workaround, title, etc.).

IChangeRepository · Interfaces/IChangeRepository.cs

Implemented by ChangeRepository.

  • GetAllAsync(stateFilter)→Returns changes, optionally filtered by state code. Reviewers are enriched per-item.
  • GetByIdAsync(changeId)→Returns a single change with full reviewers and affected service slugs.
  • CreateAsync(CreateChangeRequest)→ intInserts a new change.
  • UpdateStateAsync(id, stateCode, actorUserId)→ voidState transition.
  • VoteAsync(id, userExtId, voteCode, comment)→ voidRecords an approval vote from a reviewer.

IKbRepository · Interfaces/IKbRepository.cs

Implemented by KbRepository.

  • SearchAsync(query, categoryId)→Full-text search over article titles and snippets. Filters by category if provided.
  • GetByIdAsync(articleId)→Returns a single article with full body and enriched tags.
  • GetCategoriesAsync()→Returns all KB categories with article counts.
  • IncrementViewsAsync(articleId)→ voidAtomically increments the view counter.
  • VoteHelpfulAsync(articleId, helpful)→ voidIncrements HelpfulCount or NotHelpfulCount depending on the helpful boolean.

IActivityRepository · Interfaces/IActivityRepository.cs

Implemented by ActivityRepository. Handles audit events, comments, watchers, and notifications.

  • GetByParentAsync(parentType, parentId)→Returns ActivityEvent records for a given ticket (parentType = incident|problem|change).
  • GetCommentsByParentAsync(parentType, parentId)→Returns Comment records for a given ticket.
  • AddCommentAsync(parentType, parentId, authorExtId, body, isInternal)→ intCalls itil.usp_AddComment stored procedure; returns new CommentId.
  • GetWatchersAsync(parentType, parentId)→Returns the list of users watching a ticket.
  • AddWatcherAsync(parentType, parentId, userExtId)→ voidSubscribes a user to notifications on this ticket.
  • RemoveWatcherAsync(parentType, parentId, userExtId)→ voidUnsubscribes a user from this ticket.
  • GetUnreadNotificationsAsync(userExtId)→Returns unread Notification records for the user.
  • MarkNotificationsReadAsync(userExtId)→ voidMarks all notifications read for the user.

IUserRepository · Interfaces/IUserRepository.cs

Implemented by UserRepository. Read-only lookups used by controllers and features (write operations go through AdminRepository).

  • GetAllAsync()→Returns all active users with role and group names.
  • GetByExternalIdAsync(externalId)→Looks up a user by their identity-provider ID.
  • GetGroupsAsync()→Returns all active groups.
  • GetServicesAsync()→Returns active services with health status and open incident count.
  • GetConfigurationItemsAsync()→Returns all active CIs for the new-incident form dropdown.

ISlaRepository · Interfaces/ISlaRepository.cs

Implemented by SlaRepository. Provides both breach evaluation and analytics read methods. The DTOs SlaStats, SlaByPriority, TeamLoad, and DailyVolume are defined in this interface file.

  • EvaluateBreachesAsync()→ voidCalls reporting.usp_EvaluateSlaBreaches stored procedure. Called by SlaBackgroundService on a timer.
  • GetStatsAsync(days)→ SlaStatsKPI summary: open incidents, SLA risk count, changes this week, avg resolution, met %, breach count.
  • GetByPriorityAsync(days)→ IEnumerable<SlaByPriority>Per-priority SLA target, total incidents, met/breached counts, met %.
  • GetTeamLoadAsync()→ IEnumerable<TeamLoad>Per-team open incident count, SLA met / breach counts.
  • GetDailyVolumeAsync(days)→ IEnumerable<DailyVolume>Daily opened vs same-day-resolved counts for the trend chart.

IAdminRepository · Interfaces/IAdminRepository.cs

Implemented by AdminRepository. All CRUD operations for the Administration section of the app.

Users

  • GetUsersAsync()→ IEnumerable<User>All users with role and group names.
  • CreateUserAsync(externalId, email, displayName, title, roleId, primaryGroupId)→ intInserts user; auto-builds initials; returns new UserId.
  • UpdateUserAsync(userId, email, displayName, title, roleId, primaryGroupId, isActive)→ void

Groups

  • GetGroupsAsync()→ IEnumerable<Group>All groups with member count.
  • CreateGroupAsync(name, description)→ intAuto-generates slug from name.
  • UpdateGroupAsync(groupId, name, description, isActive)→ void

Categories & SubCategories

  • GetCategoriesAsync()→ IEnumerable<CategoryWithSubs>All categories with ticket counts and nested subcategories.
  • CreateCategoryAsync / UpdateCategoryAsync / DeleteCategoryAsync→ int/voidDeleteCategory throws InvalidOperationException if open tickets exist.
  • CreateSubCategoryAsync / UpdateSubCategoryAsync / DeleteSubCategoryAsync→ int/void

Roles

  • GetRolesAsync()→ IEnumerable<Role>All roles with user count.
  • UpdateRoleAsync(roleId, displayName, description)→ voidOnly displayName and description are editable (code is immutable).

Services

  • GetAdminServicesAsync()→ IEnumerable<Service>All services with owning group, SLA tier, and open incident count.
  • CreateServiceAsync(slug, name, categoryId, owningGroupId, healthCode, slaTierId)→ int
  • UpdateServiceAsync(serviceId, name, categoryId, owningGroupId, healthCode, slaTierId, isActive)→ void

SLA Tiers

  • GetSlaTiersAsync()→ IEnumerable<SlaTier>All tiers with nested target rows.
  • CreateSlaTierAsync / UpdateSlaTierAsync→ int/void
  • SaveSlaTierTargetsAsync(tierId, targets)→ voidMERGE upsert for each priority target row.

Priority Matrix, Business Calendars, Automations

  • GetPriorityMatrixAsync() / SavePriorityMatrixAsync(rows)→Read/save the 3×3 Impact × Urgency → Priority matrix.
  • GetBusinessCalendarsAsync() / CreateBusinessCalendarAsync / SaveBusinessDaysAsync / AddHolidayAsync / DeleteHolidayAsync→Full CRUD for business hours calendars.
  • GetAutomationsAsync() / CreateAutomationAsync / UpdateAutomationAsync / ToggleAutomationAsync→Automation rule CRUD and enable/disable toggle.
