REST API Reference

All controllers live in ApertureITSM.Api/Controllers/ and are hosted at the base path /api/. The API returns JSON. 204 responses return no body. Error responses return { "error": "..." }. Swagger UI is available at /swagger in development.

Authentication
The API currently does not enforce authentication middleware — actor identity is passed as actorUserId / actorExtId in request bodies. Add authentication middleware in Program.cs before production.

NotificationHub (SignalR) · Hubs/NotificationHub.cs

WebSocket hub mounted at /hubs/notifications. Clients connect and receive real-time push events when: an incident they watch is updated, an SLA breach occurs, or a comment is posted on a ticket they watch.

Server → Client eventPayloadTrigger
IncidentUpdated{ incidentId, field, newValue }Any field/status/assignee change
SlaBreached{ incidentId, number }SlaBackgroundService detects breach
NewComment{ parentType, parentId, commentId }Comment posted via any controller
NotificationCount{ unreadCount }After marking notifications read
