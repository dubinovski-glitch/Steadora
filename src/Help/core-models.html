Domain Models

All C# model classes live in ApertureITSM.Core/Models/. They are plain C# classes and records — no ORM attributes, no business logic. Dapper maps SQL result columns directly to their properties by name.

ITIL Entities

The three primary ITIL ticket types. All live in the itil database schema and share common concepts (priority, assignment, linked services).

Incident · src/ApertureITSM.Core/Models/Incident.cs

The central ticket type. Tracks a disruption to a service from creation through resolution, with full SLA tracking fields. Returned by IncidentRepository and surfaced through IncidentsController.

SLA Fields
slaTargetMinutes, slaStartedAt, slaPausedSeconds, slaBreachedAt, slaWarnedAt, and slaPercent are populated by the SlaBackgroundService and the SLA stored procedure. They drive the SlaBar UI component.

Admin Configuration Models

Defined in Models/AdminModels.cs. Used exclusively by the Admin feature. Stored in the admin database schema.

SlaTier & SlaTierTarget

Tiered SLA policies. Each service is assigned one tier. Each tier has per-priority response and resolution targets. Used by the SLA evaluation engine.

BusinessCalendar, BusinessDay, BusinessHoliday

Define working hours for SLA calculations when Calculate247 = false. A calendar has 7 potential day entries (Mon–Sun) and a list of holidays.

ModelKey Properties
BusinessCalendar CalendarId, Name, Timezone (IANA name), IsDefault, Days[], Holidays[]
BusinessDay DayId, CalendarId, DayOfWeek (0=Sunday), StartTime (HH:mm), EndTime (HH:mm)
BusinessHoliday HolidayId, CalendarId, HolidayDate (YYYY-MM-DD), Name
